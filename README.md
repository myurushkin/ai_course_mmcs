# Агентный ИИ: теория и инженерия

Материалы курса для магистрантов MMCS, осень 2026. Здесь лежат слайды и практики по неделям: материалы недели появляются к её началу.

Агент — это модель в цикле: она выбирает вызов инструмента, наш код его выполняет и возвращает результат. Курс разбирает каждый слой такой системы и учит собирать из них работающие агенты.

## С чего начать

Соберите рабочее окружение по [инструкции недели 1](week1/setup.md) — без него практики делать нечем. Дальше идите по неделям.

## Что понадобится

Своя машина с Python и VS Code, агент для кода (Claude Code, Codex или другой) и ключ к модели через OpenAI-совместимый API. Подписки на сервисы студент оплачивает сам; подойдёт любой сервис, работающий из России без VPN. Ключ нужен с первого занятия: имитации модели в практике нет, и без ключа ноутбук останавливается.

## Данные

Практика недели 2 использует снимок [OpenStreetMap](https://www.openstreetmap.org/copyright) по Ростову-на-Дону: 8860 мест. Данные OSM распространяются по лицензии ODbL, снимок лежит в `week2/practice/data/`.
