## Лекция

Слайды: [L01.pdf](slides/L01.pdf).

Разбираем, чем агент отличается от чат-бота и от скрипта: модель в цикле, инструменты, наблюдения, остановка. Смотрим, из чего на самом деле состоят популярные агенты для кода, и почему надёжность измеряется повторами, а не одним удачным запуском.

## Что сделать к следующему вторнику

Собрать рабочее окружение по [инструкции](setup.md): Python и uv, VS Code, агент для кода, доступ к модели через OpenAI-совместимый API. К началу второй встречи окружение должно работать — практика идёт в нём.

Кому окружение собрать не удалось, второй вторник можно пережить в Google Colab, но дальше без своей машины будет тяжело.
